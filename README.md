# AI RAG 幻觉对比实验

# 项目简介
本项目通过对比"直接调用LLM"和"使用RAG（检索增强生成）"
两种方式回答同一问题，验证RAG技术能否有效减少AI幻觉。

# 背景
在设计AI产品时，直接调用大语言模型容易产生"幻觉"——
即生成看似合理但实际错误的内容。本实验构建了一个简化的
RAG系统，证明给AI提供真实知识库后，能显著提升回答准确性。

# 测试场景
以成人教育招生顾问场景为例，知识库包含自考、成考、网教
三种学历提升方式的真实信息。

# 实验结果
针对问题"网教需要考试吗？"：
- 没有RAG：AI编造了不准确的回答，声称网教需要考试
- 有RAG：AI基于知识库准确回答"网教不需要考试"

# 技术栈
- Python
- Google Gemini API
- 简化版关键词检索（生产环境建议使用向量搜索）

# 如何运行
1. 安装依赖：`pip install` 相关库
2. 将代码中的 API_KEY 替换为你自己的 Gemini API Key
3. 运行 `python rag_demo.py`
